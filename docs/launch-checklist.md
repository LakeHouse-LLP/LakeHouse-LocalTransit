# Launch checklist

For public **LakeHouse Studio** / Template-OpenSource product launches. Complete [seo-checklist.md](seo-checklist.md) first.

## Product readiness

- [ ] README + social preview + topics/description green (discoverability CI)
- [ ] Tagged **release** with notes, checksums, attestation ([releasing.md](releasing.md))
- [ ] Demo **GIF or short MP4** in `docs/media/` (alt text; no client or confidential firm content)
- [ ] Docs page live on custom `domain` (or explicitly deferred by Sen)
- [ ] Security: private vulnerability reporting on; gitleaks clean

## Announcements

- [ ] **GitHub Discussions** announcement in the product repo (and org discussion if enabled)
- [ ] **Product Hunt** listing (Sen owns the account/timing)
- [ ] **Hacker News** Show HN (honest title; link demo + repo)
- [ ] **Reddit** — relevant subs only, follow each sub’s rules: `r/Revit`, `r/rhino`, `r/architecture` (no spam crossposts)
- [ ] **LinkedIn** + **X** — short post with social preview; link custom domain
- [ ] **McNeel Food4Rhino** listing when the tool is Rhino/Grasshopper-relevant
- [ ] **Autodesk App Store** listing when the tool is Revit/Autodesk-relevant

## After posting

- [ ] Pin the Discussions announcement
- [ ] Update org **pinned repos** if this is now a flagship
- [ ] Submit to 1–2 [awesome lists](awesome-lists.md) after the release tag exists
- [ ] Watch Search Console / Bing for crawl errors ([search-and-analytics.md](search-and-analytics.md))

## Tone

Warm, practical, lakeside-office calm — not hype. Lead with who it helps (designers and small offices) and what problem goes away.
