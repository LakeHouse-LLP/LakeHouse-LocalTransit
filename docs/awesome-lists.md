# Submitting to awesome lists

Zero-cost discovery channel for **LakeHouse Studio** open-source repos. Prefer lists that match the audience (AEC, Revit, Rhino, design tools, TypeScript).

## Before you submit

- [ ] Public repo with clear README (keyword-rich first paragraph — [discoverability.md](discoverability.md))
- [ ] License file present
- [ ] At least one **tagged release**
- [ ] Demo GIF/video or screenshots under `docs/media/` (no client or confidential firm content)
- [ ] Homepage on custom `domain` when available (never `*.github.io`)
- [ ] Topics set (8–20)

## How to submit

1. Find a maintained list (example categories: awesome-architecture, awesome-rhino, awesome-revit, awesome-design-tools — verify each list’s real name and activity).
2. Read **that** list’s `CONTRIBUTING.md` (PR format, alphabetical order, one link per PR, etc.).
3. Fork → branch → add your link with a **one-line** description that starts with the product name.
4. Open a **draft** PR if the list allows; otherwise a normal PR. Do not spam multiple lists with identical copy on the same day.
5. Be polite; if rejected, fix the README/release gap before retrying.

## Copy pattern

```text
- [ProductName](https://github.com/OWNER/REPO) - Short factual blurb for designers/small offices (Revit/Rhino/…).
```

Build `OWNER` from `github.repository_owner` / `org.json` — do not hardcode the org login in templates.

## Do not

- Buy placements or use link farms.
- Submit unfinished repos or private tools.
- Mention clients or confidential firms.
