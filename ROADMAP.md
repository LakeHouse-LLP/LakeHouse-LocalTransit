# Roadmap

High-level direction for **LakeHouse Studio** — an all-in-one digital office for designers and small offices. Details and scheduling live in [SenZhang-Plus/SenZhang-Todo](https://github.com/SenZhang-Plus/SenZhang-Todo). Community **Ideas** welcome in Discussions.

This repository is **Template-OpenSource**: the general-purpose public starter (**no** LakeHouse widget concepts). Widget work belongs in Template-Widget.

## Near term

- Solidify template defaults (community health, release, discoverability, contributor paths)
- Seed **3–5** `good first issue` / `help wanted` issues ([docs/starter-issues.md](docs/starter-issues.md))
- Stand up the Astro Starlight docs site on the custom domain ([docs/docs-site.md](docs/docs-site.md))
- Ship regular SemVer releases so newcomers see momentum

## Next

- Expand public tools around Revit / Rhino / Grasshopper / design-office workflows (from products created from this template)
- Improve onboarding (Codespaces, 5-minute setup, listings on good-first-issue sites)
- Keep brand dark-only with accent `#7DFFFF` as the final brand guide lands
- Wire local workflows to org `{owner}/.github` reusable workflows when those drafts merge

## Later / ideas

- Richer demo media and Food4Rhino / Autodesk listings where relevant ([docs/launch-checklist.md](docs/launch-checklist.md))
- Broader awesome-list presence ([docs/awesome-lists.md](docs/awesome-lists.md))

## Not planned

- Paid GitHub features required for core workflow
- Self-hosted runners on public repos
- LakeHouse widget SDK / `widget.json` / host compatibility in this template
- Auto-archive or second-owner requirements

Propose changes via Discussions **Ideas** or a small issue — thank you.
