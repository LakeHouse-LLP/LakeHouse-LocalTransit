# Support

**LakeHouse Studio** — we want designers and small offices (and contributors) to get unstuck quickly. Response-time **goals** live in [GOVERNANCE.md](GOVERNANCE.md).

## How to get help

| Need | Where |
| --- | --- |
| Questions / discussion | **Discussions** — prefer **Q&A**; also Ideas and Show and tell (Sen enables categories) |
| Bug reports | Issue form: **Bug report** |
| Feature ideas | Issue form: **Feature request** or Discussions **Ideas** |
| First contribution | Issues labeled `good first issue` / `help wanted` — [docs/starter-issues.md](docs/starter-issues.md) |
| Tracked epics / todos | [SenZhang-Plus/SenZhang-Todo](https://github.com/SenZhang-Plus/SenZhang-Todo) — not GitHub Issues |

Blank issues are disabled when Sen configures issue forms. Questions belong in Discussions, not Issues.

Org login / brand / public domain: [`.lakehouse/org.json`](.lakehouse/org.json). Do not hardcode the org login in docs or badges.

## Scope

- This repo is **Template-OpenSource** (general-purpose OSS; no LakeHouse widget concepts).
- Sibling: **Template-Widget** for LakeHouse-extensible widgets.
- Org defaults: `{owner}/.github` (draft stack today — prefer when published).
- There is no second owner and no auto-archive policy.
- **No automated stale bot** — see [GOVERNANCE.md](GOVERNANCE.md).

## Security

See [SECURITY.md](SECURITY.md). Use private vulnerability reporting; never post secrets publicly.
